# 疊疊高樓

在明亮卡通城市裡蓋摩天大樓：吊車擺盪、抓時機放下樓層，樓層疊歪了整棟會搖晃、傾倒。3D（Three.js），手機、平板、桌機都能玩。

- **單人挑戰**：每次樓層倒塌（含完全放空）失去一顆愛心，愛心用完結束；**沒有樓層上限**，背景會一路換到太空與銀河。最高紀錄存在本機。
- **對電腦輪流**：在同一棟樓上輪流放樓層，讓樓倒的人失去愛心，沒愛心就淘汰，最後留下的人獲勝。可選 1～3 個電腦。
- **線上對戰**：大廳、房間（2～4 位真人或電腦）、觀戰、玩家／觀戰邀請連結、聊天室、房主踢人、斷線 30 秒內可重連。**沒有任何真人玩家時房間立即自動關閉**（電腦與觀戰者不算），邀請同時失效且不可復活。
- 四段難度：幼幼班／簡單／普通／困難（樓層大小、地基寬度、吊車速度、完美容許值、愛心數都不同）。電腦差異可觀察：幼幼班大誤差亂放，簡單偶爾試算，普通會試算並重瞄，困難試算 13 個位置挑最穩（實測單人 1 命平均可蓋 100 層以上，測試上限）。

## 玩法與規則

- 吊車繩下掛著樓層，永遠沿畫面左右擺盪（鏡頭固定正對樓房，和《Tower Bloxx》一樣）。按「放下」（空白鍵／Enter／↓／點畫面）的瞬間，樓層落在當下的位置。
- 樓層不會被切掉。每個接縫都檢查：該接縫以上所有樓層的**重心**是否落在下方樓層的接觸面內；超出就從最低失敗的接縫往上整段傾倒。
- 與頂樓完全沒有重疊就直接掉到旁邊（算一次倒塌）。
- 偏差小於容許值為「完美」：自動對齊並累積連擊加分。穩定度條與樓層搖晃幅度反映目前最糟接縫的重心比例。

## 風

- 風力隨高度增強：1–2 層無風，約 50～90 層最強（噴射氣流），之後減弱，**140 層以上（太空）無風**。**風向與風速每一回合都不固定**（有左有右、強弱不一）。
- 兩種影響：① 吊車的擺盪中心被吹偏（`bias`）；② 樓層放下後在空中被吹走一段（`drift`）。最大值依難度：幼幼班 0.4／0.35、簡單 0.8／0.7、普通 1.2／1.1、困難 1.6／1.5（單位同樓層寬度）。
- 畫面右下角顯示風向與 1～5 級風力；白色預測框已把風算進去；雲、雨、風線、飛行物都順風。
- 規則由伺服器依種子決定，所有玩家與觀戰者看到同一個風；電腦會預判風，但估計有誤差（幼幼班 50%、簡單 25%、普通 10%、困難 3%）。`createGame({ wind: false })` 可關閉。

## 樓層形狀與顏色

- 開局設定（單人、對電腦、線上建房／房內設定）有「樓層形狀」三選一：
  1. **一般**：每層標準大小（預設）。
  2. **隨機一種形狀（整場相同）**：開局由種子隨機決定一種寬窄高矮，從第 1 層起整場每層都長這樣。
  3. **整場都不規則**：每層的寬窄高矮都不同，第 1 層起就有明顯差異，約 6 層內增加到最大幅度。
- 寬度 0.55～1.5 倍、高度 0.7～1.4 倍；最大幅度依難度（幼幼班 ±30%／25%、簡單 ±40%／30%、普通 ±55%／35%、困難 ±65%／40%）。外形由種子決定，吊車手上的樓層就是下一層的樣子，預測框也跟著寬度。
- 重心判定為加權：每層質量 = 寬 × 高；每個接合面比較「上方整段的重心」與「上下兩層實際重疊區」；沒有重疊就是沒接到。規則層選項 `createGame({ shapes: 'off' | 'fixed' | 'every' })`。
- 牆面顏色依高度**平滑漸變**（色相約 42 層轉一圈），每層另有 12 色點綴與 4 種窗型。

## 太空無重力（140 層以上）

- 沒有風，改為無重力：① **磁吸**——放下的偏移被拉回中心一部分（幼幼班 60%、簡單 50%、普通 40%、困難 30%），更容易完美；② 吊車稍慢，樓層下落與搖晃變慢、手上的樓層漂浮轉動；③ 倒塌時殘骸慢慢飄散。右下角顯示「無重力・磁吸」，預測框已算入磁吸。

## 隨高度變化的背景（固定白天，只靠高度換景；高度為壓縮後的真實層次）

| 層數 | 場景 |
|---|---|
| 0–12 | 市區天際線、氣球 |
| 12–22 | 低空：鳥群飛過 |
| 22–34 | 直升機高度：直升機（旋翼轉動、閃紅燈）、低雲 |
| 34–55 | 積雨雲：天空轉灰、下雨、閃電與雷聲；往上穿出後是雲海 |
| 55–80 | 客機巡航高度：客機與白色尾跡、卷雲 |
| 80–110 | 平流層：天空漸深藍 |
| 110–140 | 大氣層邊緣：星星出現、地球弧線升起 |
| 140–190 | 太空：地球（含雲層與大氣光暈） |
| 190+ | 月球 → 火星 → 木星 → 土星（有環）→ 天王星 → 銀河（每個約隔 80–90 層） |

進入新區域會出現提示；背景天體掛在相機上，所以蓋到幾層都不會飛出畫面。實作在 `public/js/sky.js`。

## 美術方向（視覺摘要）

- 配色：天藍背景、藍／青色樓層配奶油色頂板與棕框雙窗；橘色工具箱（設定）與橘色放下鍵。
- 形狀：近立方體的樓層，**沒有屋頂**，頂板平整可無限往上疊；背景是淡色玻璃摩天樓、遠方塔吊、圓形樹與木柵欄。
- HUD（參考原作）：左上星星＋綠色進度條（穩定度）、左下金色塔標與樓層數、藍色愛心格直排。
- 場景：低角度近正面鏡頭，隨高度由白天 → 夕陽 → 夜空與星星；熱氣球、遠方吊車。
- 動態：繩擺、落下灰塵與鏡頭震動、完美時兩側噴出星星與白煙；設定可開「減少動態」。
- 音訊：全部用 WebAudio 即時合成，**沒有外部授權素材**；背景音樂與音效可獨立開關與調音量。

## 測試與檢查

```bash
npm test             # 多語系字典、GA4、SEO 注入、暫停提示日期、規則／AI／房間單元測試（26 項）
npm run verify       # npm test + 真實伺服器的線上整合檢查（22 項，含亂填資料防護、建房限速、latency:ping）
npm run tap:check        # 點螢幕任何位置放下（桌機滑鼠／手機平板觸控），按鈕與彈窗不誤放（需先 npm start）
npm run tap:online       # 線上對局的點擊：非輪到者／觀戰者不放下、輸入框聚焦時只失焦（需先 npm start）
npm run langmenu:check   # 語言選單：鍵盤／Esc／返回鍵，對局中不誤觸「放下」（需先 npm start）
npm run overlap:check    # 右上角語言／設定／延遲鈕不蓋住標題與按鈕（三語 × 五種尺寸，需先 npm start）
npm run i18n:check   # 瀏覽器檢查英文／簡體各畫面沒有殘留繁體字串、語言切換可用（需先 npm start）
npm run audit        # 版面巡檢（Playwright）：5 種尺寸方向 × 所有畫面（BASE=http://localhost:3090/）
npm run screenshots  # 擷取實際遊戲畫面到 screenshots/（可用 ONLY=… 分批）
node scripts/online-ui.js   # 3 個瀏覽器（房主／玩家／觀戰）的線上畫面端對端
```
`audit`、`screenshots` 需要 Playwright 瀏覽器與執行中的伺服器。

## 多語系、GA4、SEO 與其他非遊戲機制（沿用 shoot-balloon 等專案的做法）

- **多語系**：繁體中文（預設）、简体中文、English。語言決定順序 `?lang=` → localStorage（key `game-island-lang`，與遊戲大廳／其他遊戲同源共用）→ 繁中。設定按鈕旁的地球鈕（顯示 繁／简／EN）可切換；首頁、設定、教學、大廳畫面切換後會重新載入以完整套用，對局／房間中不打斷，離開後套用。字典以**繁中原文當 key**：程式裡寫 `t('開始')`、含變數 `t('最高蓋到 {peak} 層', { peak })`；英文在 `locales.js`，簡體由 `python3 scripts/gen-hans.py`（OpenCC）產生，用語不理想寫進該腳本的 `OVERRIDES`。伺服器送出的中文訊息（房間錯誤、系統聊天）由 `net.js` 以 `tm()` 轉成目前語言。新增文字後 `npm test` 會檢查缺漏。
- **GA4**：`analytics.js` 只在 `pjh-eric.github.io` 且有 Measurement ID 時載入 Google tag；本機、預覽網址與 `file://` 完全不動作。只送固定維度的事件（`game_start`／`game_end`／`room_create`／`room_join`／`lobby_click`／`page_view` 與模式、難度、形狀、人數、結果、時長、語言），**不送暱稱、房號、種子或邀請 token**，並關閉廣告個人化。Measurement ID 預設為遊戲小小島共用的 ID，可用 repo 變數 `GA_MEASUREMENT_ID` 覆寫；沒有任何秘密放進前端。
- **SEO**：`seo.config.json` ＋ `scripts/inject-seo.js` 在建置時把 title／description／canonical／Open Graph／Twitter／JSON-LD 與 GA 設定寫進 `dist/index.html`，並產生 `sitemap.xml`（`public/robots.txt` 指向它）；原始碼的 `public/index.html` 不會被改動。封面圖 `assets/images/cover.webp` 與圖示請換成正式美術。
- **線上延遲徽章**：線上大廳／房間／線上對局時，右上角設定鈕左邊顯示往返延遲（≤30ms 綠、<100ms 黃、其餘紅），每 2.5 秒用 `latency:ping` 量測，離開線上畫面即停止。
- **伺服器暫停提示**：在線上大廳／等待房間連續 30 秒連不上伺服器，才跳出「線上暫時無法連線（免費額度於次月 1 日重置，可繼續玩單機）」；首頁、單機與對局中不計時，連上即取消，同一次故障只提示一次。
- **回遊戲大廳**：首頁左上角連結（帶 `?lang=` 同步語言），點擊會送 `lobby_click`。

public/js/i18n.js     多語系核心（繁中／简体／English）；locales.js（英文）、locales-hans.js（簡體，自動產生）

## 部署（預設：GitHub Pages 前端 + Render 後端）

**後端（Render）**：以 `render.yaml` 建立 Blueprint（Web Service，`region: singapore`，`/health` 健康檢查）。
在 Render 服務設定環境變數：`GAME_ALLOWED_ORIGIN` = 前端網址（例如 `https://<帳號>.github.io`，可逗號分隔多個）。`PORT` 由 Render 提供。
> Render 不支援修改既有服務的 region；已建立在其他 region 的服務需建立替代服務、再更新 `GAME_SERVER_URL`，確認 `/health` 與線上對局正常後才停用舊服務。

**前端（GitHub Pages）**：Repository → Settings → Pages → Source 選 *GitHub Actions*；
Settings → Secrets and variables → Actions → **Variables** 新增一個變數 `GAME_SERVER_URL` = Render 後端的公開 HTTPS 網址（例如 `https://house-stack-server.onrender.com`）。推送到 `main` 即由 `.github/workflows/pages.yml` 先跑 `npm test`、再建置並注入（可另設 `GA_MEASUREMENT_ID` 變數；`.github/workflows/ci.yml` 每次 push／PR 跑測試）。
前端沒有任何寫死的伺服器網址；production 不會回退到 localhost；未設定時線上對戰會顯示可讀的說明，單機與對電腦仍可玩。

**免費層注意**：Render 免費服務閒置會休眠，第一次連線可能需要約 30 秒（大廳會顯示等待提示）；房間只存在記憶體，服務重啟就消失，視為可清理的暫時狀態，不做伺服器端排行榜。

| 環境 | 指令 | 說明 |
|---|---|---|
| 本機 | `npm start` | 同源提供前端與後端 |
| 預覽 | `GAME_SERVER_URL=http://localhost:3090 npm run build:pages` | 產生 `dist/` 檢查 Pages 建置 |
| Production | 推送 `main` | Pages 自動部署；Render autoDeploy |

## 已採用的假設

- 任何一次樓層倒塌（含完全放空）都失去 1 顆愛心；對戰愛心依難度（幼幼班 3、簡單 2、普通 2、困難 1）。
- 對戰輪到的玩家限時（幼幼班 40 秒、簡單 30、普通 25、困難 20），逾時自動在吊車目前位置放下。
- 對戰為共用同一棟樓；不含「各蓋各的比高度」模式。預設沒有樓層上限（規則層保留 `maxFloors` 選項，達到即登頂結束）。
- 邀請連結不設時限，與房間同生命週期，房主可「撤銷並重發」；玩家席滿或對局進行中，玩家邀請會轉成觀戰並明確提示。
- 邀請連結不會自動進房：先停在大廳顯示房間與可編輯暱稱，確認後才加入；伺服器消毒暱稱，角色由 token 決定。
- 風沒有設定開關（規則層有 `wind` 選項）；尚未實作隕石與「慣性釋放」等其他無重力玩法。
- 需要支援 WebGL 的瀏覽器；不支援時顯示說明頁。純文字教學；介面支援繁中／简体／English（沒有其他語言）。
- GA4 的 Measurement ID 沿用遊戲小小島共用的 ID、站台網址假設為 `https://pjh-eric.github.io/house-stack/`（repo 名稱 `house-stack`）；若實際 repo 名稱不同，請改 `seo.config.json`。簡體中文為 OpenCC 自動轉換、英文為人工翻譯，尚未經母語者校對。
